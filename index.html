Git Branch Push & Đóng Gói Dữ Liệu Vĩnh Viễn

Xuất file index.html đã nhúng sẵn dữ liệu mới nhất để push lên GitHub

1 Đóng gói toàn bộ môn học vào file index.html

Mọi môn học, từ vựng và câu trắc nghiệm bạn vừa thêm trên web sẽ được ghi cứng vào mã nguồn của file index.html tải về. Lưu đè file này vào thư mục Git của bạn.

2 Lệnh đẩy lên nhánh Git (Git Branch CLI Helper) 
# 1. Kiểm tra trạng thái file sau khi ghi đè index.html mới tải về
git status

# 2. Đưa file index.html vào vùng chuẩn bị (Staging)
git add index.html

# 3. Tạo commit lưu lại nội dung môn học & ngân hàng đề mới
git commit -m "chore(lms): update courses and quiz database"

# 4. Đẩy trực tiếp lên nhánh main của GitHub
git push origin main

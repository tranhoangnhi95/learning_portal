Bài 1 (第十三课)

这是不是中药 (Đây có phải là thuốc đông y không?)

Zhè shì bú shì zhōngyào • Lượng từ, Câu vị ngữ tính từ & Chữ 的

Từ Vựng & Thuật Ngữ Cốt Lõi (Nhấn vào thẻ để nghe phát âm)

箱子
/xiāngzi/
Vali, thùng, hộp to (Lượng từ: 个)
VD: 这个箱子很重。
重 / 轻
/zhòng / qīng/
Nặng / Nhẹ
VD: 香蕉很重，橘子很轻。
黑 / 红
/hēi / hóng/
Màu đen / Màu đỏ
VD: 这些黑的是中药。
旧 / 新
/jiù / xīn/
Cũ / Mới
VD: 他的手机很旧了。
中药
/zhōngyào/
Thuốc đông y (>< 西药: thuốc tây)
VD: 这是不是中药？
茶叶
/cháyè/
Lá trà
VD: 这不是药，这是茶叶。
日用品
/rìyòngpǐn/
Đồ dùng hàng ngày
VD: 箱子里都是日用品。
把
/bǎ/
Chiếc, cái (Lượng từ vật có cán/tay cầm)
VD: 一把雨伞 / 一把钥匙 / 一把椅子
张
/zhāng/
Tấm, tờ, chiếc (Vật có mặt phẳng)
VD: 两张光盘 / 一张纸 / 一张床
本
/běn/
Quyển, cuốn (Sách, từ điển, tạp chí)
VD: 一本书 / 一本词典
件
/jiàn/
Bộ, chiếc (Quần áo, áo mưa, sự việc)
VD: 两件衣服 / 一件雨衣
支
/zhī/
Cây, chiếc (Bút, vật cán dài nhỏ)
VD: 三支笔
瓶
/píng/
Chai, lọ, bình
VD: 一瓶香水 / 两瓶啤酒

Mục Tiêu Trọng Tâm Slide (教学目标)

  • ✓ Sử dụng chuẩn xác các lượng từ: 把 (có cán/tay cầm), 张 (bề mặt phẳng), 本 (sách vở), 件 (quần áo), 支 (bút), 瓶 (chai lọ)
  • ✓ Nắm vững Câu vị ngữ hình dung từ (Chủ ngữ + 很/不 + Tính từ)
  • ✓ Biến đổi câu đồng nghĩa với cụm từ chữ “的” (这是我妈妈的汉语书 <=> 这本汉语书是我妈妈的)

Công Thức Ngữ Pháp & Lưu Ý Thi (语法)

Cụm từ chữ “的” (的字短语)
Danh từ / Đại từ / Tính từ + 的 = Cụm danh từ

Biến đổi câu đồng nghĩa: 这是我妈妈的汉语书 <=> 这本汉语书是我妈妈的 | 这是两辆新摩托车 <=> 这两辆摩托车是新的.

Hướng Dẫn Đưa Web Lên Host Mở Miễn Phí

Có ngay đường link online (.netlify.app / .vercel.app / .github.io) để học trên cả điện thoại & máy tính

Bước 1: Tải file trang web độc lập này về máy
Toàn bộ code + dữ liệu các môn bạn vừa thêm sẽ được gói gọn trong 1 file index.html duy nhất.
Cách 1: Kéo-Thả trên Netlify Drop (Nhanh nhất - 30 giây) Khuyên dùng
  1. Tạo một thư mục mới trên máy tính (ví dụ đặt tên là cong-hoc-tap-vb2) và bỏ file index.html vừa tải vào trong thư mục đó.
  2. Truy cập trang chủ app.netlify.com/drop (đăng nhập miễn phí bằng Gmail/GitHub).
  3. Kéo nguyên thư mục cong-hoc-tap-vb2 thả vào ô "Drag and drop your site output folder here".
  4. Chờ 5 giây, Netlify sẽ cấp ngay cho bạn một đường link vĩnh viễn (VD: hoc-vb2-ngon-ngu-anh.netlify.app). Khi có môn mới, bạn chỉ cần bấm "Tải index.html" ở Bước 1 rồi kéo thả lại là web tự cập nhật!
Cách 2: Đưa lên GitHub Pages hoặc Vercel
  1. Tạo một Repository mới trên GitHub.com, nhấn Add file → Upload files và tải file index.html lên.
  2. Vào mục Settings → Pages của Repository, ở mục Branch chọn main rồi bấm Save.
  3. Sau 1 phút, trang web của bạn sẽ hoạt động tại địa chỉ https://<ten-ban>.github.io/<ten-repo>.
